OUI Clearance System

The OUI Clearance System is an official digital clearance platform built for Oduduwa University, Ipetumodu, Osun State, Nigeria. It was developed to replace the slow, manual, paper-based clearance process that required students to physically visit multiple offices across campus before graduating.

With this system, a student can submit all their required receipts — school fees, medical, and library — directly from their phone or laptop. Each receipt is reviewed by the responsible staff member in real time. The moment any stage is approved or queried, the student receives an instant notification both inside the app and via email, so they always know exactly where their application stands without having to chase anyone.

The clearance follows a structured workflow. The Admin reviews school fees receipts, the Medical Manager reviews medical receipts, and the Library Manager reviews the library receipt — all simultaneously. Once all three approve, the Head of Department is automatically notified to give the departmental sign-off. After the HOD approves, the Admin does one final check and grants the clearance. The student then receives an official, university-branded clearance letter as a downloadable PDF, complete with a unique certificate ID for verification.

The system supports five distinct roles — Student, Admin, Medical Manager, Library Manager, and Head of Department — each with their own dedicated dashboard showing only what they need to see and do.

It was built with React and Tailwind CSS on the frontend, Node.js and Express on the backend, PostgreSQL as the database, and Socket.io for real-time communication.
